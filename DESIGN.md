# Original design source

The eight views come from the rendered operator-started RADAR application at http://127.0.0.1:8000/. The candidate preserves the original document rendering mode, stylesheet order, typography, graphics, content, colors and responsive styles.

Original font binaries and media use relative asset paths. The font stylesheet rewrites its asset URLs for a repository subpath. Costs and Monitor use the original SVG render for the captured desktop and mobile chart sizes. The static controller renders captured report and result fragments, updates their navigation state and links between captured pages.
