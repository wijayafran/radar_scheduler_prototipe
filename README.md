# RADAR Sample Mode

A browser-only stakeholder demo of the RADAR workspace. Open the landing page and choose **Continue with Sample Mode**. The fixed sample contains 220 generated research results and 13 report pages each in English and Indonesian. All people, observations, accounts, settings and financial values are fictional.

Serve this directory with a static HTTP server. Routes use hashes, and JavaScript, CSS and media paths are relative to the site root. The same files work at the GitHub Pages project subdirectory. No installation or backend is required.
